# Игра «Слова из слова» (прототип для Яндекс Игр)

Связано: [niche-analysis.md](niche-analysis.md)

## Состояние (2026-10-21)
- Решение пользователя: пробуем казуальную игру для Яндекс Игр, концепция «Слова из слова» (круг букв, составляем слова из длинного слова).
- Репозиторий: https://github.com/Viktor-CSKA/Slova_app (ветка `main`). Чистый HTML + JS-модули, без сборки; `tools/serve.mjs` (локальный сервер), конфигурация предпросмотра `slova` в `.claude/launch.json` (порт 5173). Отправка в GitHub (`git push`) — в терминальной панели и только по просьбе владельца.
- Готово и проверено в браузере (размер телефона): жест по кругу букв, ввод с клавиатуры, проверка слов, подсказка, переход на следующий уровень, сохранение прогресса, заглушка рекламы. Тесты логики: `node --test test/logic.test.mjs` (8 зелёных; из папки репозитория, указывать файл, не папку).
- Архив для консоли: `dist/slova.zip` (≈260 КБ; папка `dist/` в .gitignore).

```bash
tar -a -c -f dist/slova.zip index.html css js data
```

## Как устроено
- `js/logic.js` — чистая логика (нормализация ё→е, `canForm`, `subWords`, детерминированная книга уровней `createLevelBook`, цель уровня `goalFor`). Базовая длина слова растёт: 5 букв до уровня 5, 6 до 15, 7 до 40, затем 8.
- `js/sdk.js` — обёртка Yandex Games SDK; вне Яндекса подставляется заглушка рекламы. `loadingReady()` вызывается, когда можно играть; `gameplayStart/Stop` вокруг игры, рекламы и окна уровня.
- `js/storage.js` — прогресс в localStorage (уровень, найденные слова, подсказки).
- `js/main.js` — интерфейс и ход игры.
- Реклама: полноэкранная после нажатия «Дальше» (логическая пауза), реклама с наградой за подсказку, когда бесплатные кончились (3 в начале). Таймеров рекламы нет (по правилам Яндекса это накрутка).

## Требования Яндекс Игр, которые учтены (и что осталось)
- Источник: [Game requirements](https://yandex.com/dev/games/doc/dg/concepts/requirements.html).
- Учтено: `index.html` в корне архива, нет кириллицы в именах файлов, размер << 100 МБ, прогресс сохраняется сразу, SDK подключён до `YaGames.init()`, `LoadingAPI.ready()`, нет своих «рекламных» окон, ориентация портретная, без звука.
- Не сделано: облачные сохранения через SDK (сейчас localStorage), выбор языка (игра только на русском; в черновике указать ru), иконки/обложка/скриншоты карточки, описание «Как играть», возрастной рейтинг.
- Подводные камни: на Яндекс Играх игры с рейтингом 30 и ниже через 3 недели снимают с публикации (п. 2.13); игра должна давать контент на 10+ минут или повод вернуться (п. 2.9); копии игр из каталога запрещены (п. 3.6) — «слова из слова» уже есть в каталоге, нужна отличительная особенность.

## Словарь (подключён 2026-10-22)
- Источник: `nouns.csv` (8 378 501 байт) из [Badestrand/russian-dictionary](https://github.com/Badestrand/russian-dictionary) (данные OpenRussian и Wiktionary), лицензия **CC BY-SA 4.0**. Скачан с разрешения пользователя в папку рабочей области (вне проекта), в проект положены только результат и текст лицензии.
- Преобразование: `node tools/build-dict.mjs <nouns.csv> data/words.txt`. Берётся первый столбец; слова только из строчных букв а-я (заглавные — имена и аббревиатуры — отброшены), длина 3–8, «ё»→«е», повторы убраны, без слов без гласных, стоп-лист `tools/stoplist.txt`. Получилось 14 944 слова (≈203 КБ). Порядок источника (частотность) сохранён.
- Базовые слова уровней берутся из первых 5000 слов (самые употребимые), `minSub = 8`; подсказка открывает самое частотное из ненайденных слов; принимаются все слова словаря.
- Условия лицензии: указание авторства в игре (небольшая подпись в окне «Уровень пройден», простой текст без ссылок, чтобы не нарушить правила Яндекса о внешних ресурсах), `data/NOTICE.txt` и текст лицензии в архиве; список слов считается производным и распространяется на тех же условиях CC BY-SA 4.0. Код игры отдельный.
- Остаются редкие лишние слова-имена и аббревиатуры (например, нашли «риа», «сми», «тим»): пополнять `stoplist.txt` по ходу игры и пересобирать. Сленг и устаревшие слова в словаре есть, это допустимо, но на модерации следить за жалобами.
