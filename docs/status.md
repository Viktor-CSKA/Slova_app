# Игра «Слова из слова» (прототип для Яндекс Игр)

Связано: [niche-analysis.md](niche-analysis.md)

## Состояние (2026-10-26)
- Решение пользователя: пробуем казуальную игру для Яндекс Игр, концепция «Слова из слова» (круг букв, составляем слова из длинного слова).
- Репозиторий: https://github.com/Viktor-CSKA/Slova_app (ветка `main`). Чистый HTML + JS-модули, без сборки; `tools/serve.mjs` (локальный сервер), конфигурация предпросмотра `slova` в `.claude/launch.json` (порт 5180). Отправка в GitHub (`git push`) — в терминальной панели и только по просьбе владельца.
- Готово и проверено в браузере (размер телефона): жест по кругу букв, ввод с клавиатуры, проверка слов, подсказка, переход на следующий уровень, сохранение прогресса, заглушка рекламы; с 2026-10-26 ещё ежедневный уровень, серия дней, облачные сохранения, окно «Как играть», пауза при потере фокуса, альбомная раскладка. Тесты логики: `node --test test/logic.test.mjs test/progress.test.mjs` (20 зелёных; из папки репозитория, указывать файлы, не папку).
- Архив для консоли: `dist/slova.zip` (≈270 КБ; папка `dist/` в .gitignore). Пересобран 2026-10-26.

```bash
tar -a -c -f dist/slova.zip index.html css js data
```

## Как устроено
- `js/logic.js` — чистая логика (нормализация ё→е, `canForm`, `subWords`, детерминированная книга уровней `createLevelBook`, цель уровня `goalFor`). Базовая длина слова растёт: 5 букв до уровня 5, 6 до 15, 7 до 40, затем 8.
- `js/sdk.js` — обёртка Yandex Games SDK (`getPlayer().getData/setData` для облака, `serverTime()` для даты ежедневного уровня); вне Яндекса подставляется заглушка рекламы. `loadingReady()` вызывается, когда можно играть; `gameplayStart/Stop` вокруг игры, рекламы и окна уровня.
- `js/progress.js` — чистая логика сохранения (схема v2: уровень, найденные слова, подсказки, ежедневный уровень, серия, `seenHelp`), слияние локального и облачного сохранений (побеждает тот, где игрок дальше; серия и ежедневный выбираются отдельно), счёт дней серии, защита от частой рекламы. `js/storage.js` — localStorage (ключ `slova_save_v1`, старые сохранения читаются).
- `js/main.js` — интерфейс и ход игры.
- Реклама: полноэкранная после нажатия «Дальше» (логическая пауза), реклама с наградой за подсказку, когда бесплатные кончились (3 в начале). Таймеров рекламы нет (по правилам Яндекса это накрутка).

## Требования Яндекс Игр, которые учтены (и что осталось)
- Источник: [Game requirements](https://yandex.com/dev/games/doc/dg/concepts/requirements.html).
- Учтено раньше: `index.html` в корне архива, нет кириллицы в именах файлов, размер << 100 МБ, прогресс сохраняется сразу, SDK подключён до `YaGames.init()`, `LoadingAPI.ready()`, нет своих «рекламных» окон, ориентация портретная, без звука.
- Сделано 2026-10-26:
  - Облачные сохранения: при старте читаем `player.getData(['save'])` (таймаут 2,5 с) и сливаем с localStorage; запись в облако не чаще раза в 4 с и сразу при уходе в фон (`flush`). Без SDK работает только localStorage.
  - `GameplayAPI.start/stop`: вокруг игры, рекламы, окон уровня и справки; пауза при потере фокуса, скрытии вкладки и по событию SDK `game_api_pause` (ввод блокируется, сохранение сбрасывается).
  - Размер и ориентация: раскладка в процентах и `dvh`; в альбомной раскладке (высота ≤ 600 px) поле слева, круг справа. Проверено на 360×640, 375×740, 812×375 (границы элементов в пределах экрана).
  - Реклама без накрутки: полноэкранная только после «Дальше» и не чаще раза в 90 с (ролик с наградой тоже сдвигает окно); видео за подсказку только по нажатию игрока; таймеров рекламы нет.
  - «Как играть»: кнопка «?» и автоматический показ при первом запуске.
  - Отличительная особенность (п. 3.6, игра не копия каталога): **ежедневный уровень**: одно базовое слово из 7 букв на дату у всех игроков (хеш даты, цель 8–15 слов), серия дней подряд, +2 подсказки за прохождение; дата по серверному времени SDK (`serverTime()`), вне Яндекса по местному.
  - Мигание кнопки «Подсказка» через 20 с без находок; сообщения об ошибках красные и крупнее.
- Не сделано / решить в консоли: возрастной рейтинг (предположительно 0+, заполнить анкету), выбор языка (только ru), проверка настоящей рекламы и облака в консоли с `debug-mode=16` (без загрузки в консоль проверить нельзя).
- Подводные камни: на Яндекс Играх игры с рейтингом 30 и ниже через 3 недели снимают с публикации (п. 2.13); игра должна давать контент на 10+ минут или повод вернуться (п. 2.9; здесь ~800 разных уровней и ежедневный); копии игр из каталога запрещены (п. 3.6).

## Словарь (подключён 2026-10-22)
- Источник: `nouns.csv` (8 378 501 байт) из [Badestrand/russian-dictionary](https://github.com/Badestrand/russian-dictionary) (данные OpenRussian и Wiktionary), лицензия **CC BY-SA 4.0**. Скачан с разрешения пользователя в папку рабочей области (вне проекта), в проект положены только результат и текст лицензии.
- Преобразование: `node tools/build-dict.mjs <nouns.csv> data/words.txt`. Берётся первый столбец; слова только из строчных букв а-я (заглавные — имена и аббревиатуры — отброшены), длина 3–8, «ё»→«е», повторы убраны, без слов без гласных, стоп-лист `tools/stoplist.txt`. Получилось 14 944 слова (≈203 КБ), после стоп-листа 2026-10-26 — 14 735. Порядок источника (частотность) сохранён.
- Базовые слова уровней берутся из первых 5000 слов (самые употребимые), `minSub = 8`; подсказка открывает самое частотное из ненайденных слов; принимаются все слова словаря.
- Условия лицензии: указание авторства в игре (небольшая подпись в окне «Уровень пройден», простой текст без ссылок, чтобы не нарушить правила Яндекса о внешних ресурсах), `data/NOTICE.txt` и текст лицензии в архиве; список слов считается производным и распространяется на тех же условиях CC BY-SA 4.0. Код игры отдельный.
- Проверка 2026-10-26: прогнали уровни 1–60 и все 3-буквенные слова скриптом (игру в браузере не играли руками; вид проверен в предпросмотре). В стоп-лист добавлено ≈160 слов: оскорбления и вульгарные слова (чурка, жид, хач, жопа и т. п.), аббревиатуры (пво, нпо, оао, ооо, нато, камаз, зил и др.), имена, редкие слова-базы (валек, райком, полянин). Стоп-лист теперь читается по пробелам и строкам. `nouns.csv` в этой сессии не искали заново: стоп-лист применён к готовому `words.txt` через `tools/apply-stoplist.mjs` (результат тот же, что у пересборки). Второй проход (2026-10-26, тот же день): просмотрены все 827 базовых слов обычных уровней и 674 базовых слова ежедневного; убраны географические и личные имена (анджелес, америка, наполеон…), политические и военные аббревиатуры (госдума, партком, вермахт…), алкоголь, наркотики, сексуальные и бранные слова. Сейчас 14 735 слов. Проверены только базовые слова, остальной словарь на имена (города, фамилии) целиком не просматривался: пополнять по жалобам. Сленг и устаревшие слова остались, это допустимо; следить за жалобами и пополнять `stoplist.txt`; тест `test/progress.test.mjs` проверяет, что слова из стоп-листа не просочились.
